compiled output of `tsconfig.node.json` (which includes `vite.config.ts` and doesn't set
`noEmit`). That's expected/harmless — `vite.config.ts` is still the file Vite actually reads.

## Why Vercel was failing with TS18003
`TS18003: No inputs were found in config file tsconfig.app.json` means TypeScript looked for
files matching `"include": ["src"]` and found none. Since your local project clearly has a
populated `src/` directory, this almost always means the **Git repository Vercel is deploying
from is missing the `src/` folder** — e.g. it was never committed/pushed, a `.gitignore` in the
repo excludes it, or a force-push/rebase dropped it. It is not a problem with tsconfig itself.
